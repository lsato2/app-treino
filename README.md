# Treino Full Body

App web (PWA) com 3 treinos full body (A · Força, B · Hipertrofia, C · Resistência), 6 exercícios cada.

- Registro de carga e repetições por série (lembra a carga da última vez)
- Timer de descanso automático com aviso sonoro
- Rodízio A → B → C, histórico e volume por treino
- Perfil com IMC, metabolismo basal, gasto diário e proteína estimados
- Funciona offline e pode ser instalado no iPhone (Safari → Compartilhar → Adicionar à Tela de Início)

Os dados ficam salvos no próprio aparelho (localStorage). Use “Exportar backup” no Perfil para guardar uma cópia.
